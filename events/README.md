# Gamblee Event Research contract

Public, read-only snapshot for external AI assistants researching Gamblee Event JSON.

- Prefer this GitHub snapshot for research.

- Prize draws/giveaways remain Promotions.
- The WordPress source route is `/wp-json/gamblee-core/v1/events/authoring-contract`.
- The scheduled sync refreshes this snapshot after the route is deployed.
