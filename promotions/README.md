# Gamblee Promotion Research contract

Public, read-only snapshot for external AI assistants researching Gamblee Promotion JSON.

- Prefer this GitHub snapshot for research.
- Scheduled competitive/playable tournaments, leaderboards, races and freerolls route to Event JSON.
- Prize draws, raffles, giveaways, mystery boxes, wheels, cashback, loyalty and non-competitive missions remain Promotions.
- The WordPress source route is `/wp-json/gamblee-core/v1/promotions/authoring-contract`.
- The scheduled sync refreshes this snapshot after the route is deployed.
